# Dandori Management

**GUI App for cupposting task management by using ticket.**  
The risk of running this script is always with you.

## Preparation
Need to install following libraries by using `pip install`
* [`flask`](https://pypi.org/project/Flask/)
* [`flask-sqlalchemy`](https://pypi.org/project/Flask-SQLAlchemy/)

## Getting Started
Please start srve by following command.
```
python server.py 5000
```
Please open [`http://localhost:5000`](http://localhost:5000) on browther.
